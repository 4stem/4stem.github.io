## Πώς το προσθέτεις στο κινητό σου

Υπάρχουν δύο τρόποι, ανάλογα με το αν θέλεις το πρόγραμμα να **ενημερώνεται αυτόματα** όποτε γίνει κάποια αλλαγή, ή απλώς να το έχεις **μία φορά**.

1. Άνοιξε την εφαρμογή **Google Calendar**.
2. Πάτα **☰ → Ρυθμίσεις → Προσθήκη ημερολογίου → Εγγραφή στο ημερολόγιο**.
3. Επικόλλησε τη διεύθυνση που αντέγραψες παραπάνω.

**iPhone / iPad:**

### Β. Εφάπαξ προβολή — δεν ενημερώνεται αυτόματα

Αν θέλεις απλώς να «τσεκάρεις» το πρόγραμμα μία φορά, χωρίς μόνιμη σύνδεση: άνοιξε τον σύνδεσμο «άνοιξε σε νέα καρτέλα» πιο πάνω από το κινητό σου και θα δεις το πρόγραμμα κανονικά μέσα στον browser, χωρίς να χρειάζεται να το προσθέσεις πουθενά.

## Φτιάξε το δικό σου αρχείο ics

Το παραπάνω ημερολόγιο αντιστοιχεί στο συγκεκριμένο εβδομαδιαίο πρόγραμμα για ένα σχολείο στα Δωδεκάνησα όπου έχει προστεθεί η τοπική αργία της Ενσωμάτωσης. Αν οι δικές σου ώρες Φυσικής πέφτουν σε άλλες μέρες/ζώνες, ή έχεις άλλη τοπική αργία, χρησιμοποίησε το εργαλείο παρακάτω για να φτιάξεις το **δικό σου** αρχείο .ics — και μετά ακολούθησε τις οδηγίες εισαγωγής στο τέλος.

💡 Στο ημερολόγιο, οι σύνδεσμοι των ενδεικτικών δραστηριοτήτων γίνονται clickable όταν ανοίγεις ένα event και πατάς **«More details» / «Περισσότερες λεπτομέρειες»** — στην πρώτη προεπισκόπηση του event εμφανίζονται μόνο ως απλό κείμενο.

Εργαλείο που μετατρέπει το εβδομαδιαίο ωρολόγιο πρόγραμμα ενός/μιας εκπαιδευτικού σε πλήρες **ετήσιο πρόγραμμα διδασκαλίας**, κατανέμοντας αυτόματα τις ενδεικτικές ώρες κάθε κεφαλαίου (όπως ορίζονται στις Οδηγίες Διδασκαλίας) και προσθέτοντας ώρες επανάληψης στο τέλος κάθε ενότητας. Το αποτέλεσμα κατεβαίνει ως αρχείο **.ics**, έτοιμο για εισαγωγή σε Google Calendar (υπολογιστή ή κινητό).

### Οδηγίες χρήσης — τι κάνει κάθε ρύθμιση

1. **Εβδομαδιαίο πρόγραμμα** — κάνε κλικ στα κελιά που αντιστοιχούν στις δικές σου ώρες Φυσικής μέσα στην εβδομάδα (ξανά-κλικ αποεπιλέγει). Ο μετρητής από κάτω δείχνει πόσες ώρες/εβδομάδα έχεις επιλέξει συνολικά.
2. **Ωράριο ζωνών** — η ώρα έναρξης/λήξης κάθε διδακτικής ζώνης (1η, 2η, ... 7η). Άλλαξέ τα αν το κουδούνι του σχολείου σου χτυπάει σε διαφορετικές ώρες.
3. **Ρυθμίσεις σχολικού έτους** — ημερομηνία έναρξης διδασκαλίας, (ενδεικτική) ημερομηνία λήξης μαθημάτων, πόσες ώρες επανάληψης θέλεις στο τέλος κάθε κεφαλαίου, και τον σύνδεσμο που θα εμφανίζεται στα events επανάληψης (π.χ. study4exams — άλλαξέ τον αν χρησιμοποιείς κάτι άλλο).
4. **Αργίες σχολικού έτους** — οι εθνικές αργίες είναι ήδη προσυμπληρωμένες (μπορείς να τις σβήσεις/απενεργοποιήσεις με το check-box). Με **«+ Προσθήκη τοπικής αργίας»** προσθέτεις τη δική σου (π.χ. τοπική εορτή, απεργία, σχολική εκδρομή) — δώσε περιγραφή και ημερομηνία «από-έως».
5. **Ενότητες ύλης** — οι προσυμπληρωμένες ενότητες και ώρες αντιστοιχούν στις επίσημες Οδηγίες Διδασκαλίας του σχολικού έτους. Αν θέλεις να προσθέσεις κάτι επιπλέον σε ένα κεφάλαιο (μια ακόμη επανάληψη, εμβάθυνση σε ένα αντικείμενο, ή ένα πείραμα που δεν αναφέρεται στις Οδηγίες), κάνε το εδώ — αύξησε τις ώρες του ή πρόσθεσε τη δραστηριότητα στο πεδίο κάτω από αυτό (μία ανά γραμμή, με τον σύνδεσμό της στο τέλος) — η ζωντανή προεπισκόπηση από κάτω δείχνει πώς θα φαίνονται clickable.
6. Πάτα **«▶ ΔΗΜΙΟΥΡΓΙΑ ΑΡΧΕΙΟΥ .ICS»** για να δεις αναλυτική προεπισκόπηση όλου του προγράμματος πριν κατεβάσεις τίποτα.
7. Πάτα **«⬇ Λήψη αρχείου .ics»** για να αποθηκεύσεις το αρχείο στον υπολογιστή σου.

## Χαρακτηριστικά

- ✅ Διαδραστικό εβδομαδιαίο πρόγραμμα — επιλογή ωρών Φυσικής με κλικ
- ✅ Έτοιμη λίστα ενοτήτων/ωρών από τις Οδηγίες Διδασκαλίας Γ' Λυκείου (πλήρως επεξεργάσιμη)
- ✅ Αυτόματη προσθήκη ωρών επανάληψης στο τέλος κάθε κεφαλαίου, με σύνδεσμο για διαγωνίσματα
- ✅ Ενσωματωμένες αργίες σχολικού έτους 2026-2027 (προσθήκη/αφαίρεση/επεξεργασία)
- ✅ Ρυθμιζόμενο ωράριο ζωνών διδασκαλίας
- ✅ Προεπισκόπηση προγράμματος πριν τη λήψη
- ✅ Λήψη αρχείου .ics — εισαγωγή σε Google Calendar από υπολογιστή ή κινητό

function escAttr(s){ return String(s).replace(/&/g,'&amp;').replace(/"/g,'&quot;').replace(/</g,'&lt;'); }
function escHtml(s){ return String(s).replace(/&/g,'&amp;').replace(/</g,'&lt;').replace(/>/g,'&gt;'); }
// Μετατρέπει απλό κείμενο (μία γραμμή ανά δραστηριότητα) σε HTML με πραγματικά clickable links,
// χρησιμοποιείται τόσο στην προεπισκόπηση κάτω από κάθε textarea όσο και στον πίνακα προεπισκόπησης.
function linkify(text){
  var urlRe = /(https?:\/\/[^\s]+)/g;
  return String(text).split('\n').filter(function(l){return l.trim().length>0;}).map(function(line){
    var escaped = escHtml(line);
    return escaped.replace(urlRe, function(url){
      return '<a href="'+url+'" target="_blank" rel="noopener" style="color:var(--acc)">'+url+'</a>';
    });
  }).join('<br>');
}

function parseISODate(s){ var p=s.split('-').map(Number); return new Date(p[0],p[1]-1,p[2]); }
function fmtISODate(dt){ return dt.getFullYear()+"-"+String(dt.getMonth()+1).padStart(2,'0')+"-"+String(dt.getDate()).padStart(2,'0'); }
function isHoliday(dt, holidays){
  var t = dt.getTime();
  return holidays.some(function(h){
    if(!h.on) return false;
    var s = parseISODate(h.start).getTime();
    var e = parseISODate(h.end||h.start).getTime();
    return t>=s && t<=e;
  });
}

function buildUnits(chapters, reviewHours, reviewUrl){
  var units = [];
  chapters.forEach(function(ch){
    var notes = (ch.notes && ch.notes.length) ? ch.notes : null;
    for(var i=1;i<=ch.hours;i++){
      var note = notes ? notes[(i-1) % notes.length] : null;
      units.push({type:'lesson', chapter:ch.name, label: ch.name + " (ώρα " + i + "/" + ch.hours + ")", note: note});
    }
    for(var r=1;r<=reviewHours;r++){
      units.push({type:'review', chapter:ch.name, label:"Επανάληψη – " + ch.name + " (" + r + "/" + reviewHours + ")", url: reviewUrl});
    }
  });
  return units;
}

// ---------- Αλγόριθμος χρονοπρογραμματισμού ----------
function scheduleUnits(units, weeklySlots, periodTimes, startDate, endDate, holidays){
  var slotsByDay = {};
  weeklySlots.forEach(function(s){
    if(!slotsByDay[s.day]) slotsByDay[s.day]=[];
    slotsByDay[s.day].push(s.period);
  });
  Object.keys(slotsByDay).forEach(function(k){ slotsByDay[k].sort(function(a,b){return a-b;}); });

  var results = [];
  var cursor = new Date(startDate.getTime());
  var ui = 0;
  var hardEnd = new Date(endDate.getTime());
  hardEnd.setDate(hardEnd.getDate()+1);

  while(ui < units.length && cursor < hardEnd){
    var dow = cursor.getDay();
    var mon1 = dow===0?7:dow;
    if(mon1>=1 && mon1<=5 && slotsByDay[mon1] && !isHoliday(cursor, holidays)){
      for(var i=0;i<slotsByDay[mon1].length && ui<units.length;i++){
        var period = slotsByDay[mon1][i];
        var u = units[ui++];
        var pt = periodTimes[period];
        results.push({
          date: fmtISODate(cursor),
          dayName: DAY_NAMES_JS[dow],
          period: period,
          start: pt.start,
          end: pt.end,
          type: u.type,
          chapter: u.chapter,
          label: u.label,
          note: u.note || "",
          url: u.url || ""
        });
      }
    }
    cursor.setDate(cursor.getDate()+1);
  }
  return {results: results, scheduled: ui, total: units.length};
}

// ---------- ICS ----------
function icsEscape(s){
  return String(s).replace(/\\/g,'\\\\').replace(/;/g,'\\;').replace(/,/g,'\\,').replace(/\n/g,'\\n');
}
function foldLine(line){
  if(line.length<=74) return line;
  var out=[]; var i=0;
  while(i<line.length){
    var chunk = i===0 ? line.slice(0,74) : line.slice(i, i+73);
    out.push((i===0?"":" ")+chunk);
    i += (i===0?74:73);
  }
  return out.join("\r\n");
}
function toUtcStamp(dateStr, timeStr){
  var dp = dateStr.split('-').map(Number);
  var tp = timeStr.split(':').map(Number);
  var d = new Date(dp[0], dp[1]-1, dp[2], tp[0], tp[1], 0);
  return d.toISOString().replace(/[-:]/g,'').split('.')[0]+"Z";
}
function buildICS(results){
  var now = new Date().toISOString().replace(/[-:]/g,'').split('.')[0]+"Z";
  var lines = [];
  lines.push("BEGIN:VCALENDAR");
  lines.push("VERSION:2.0");
  lines.push("PRODID:-//kathimerinotita//programma-fysikis//EL");
  lines.push("CALSCALE:GREGORIAN");
  lines.push("METHOD:PUBLISH");
  lines.push(foldLine("X-WR-CALNAME:" + icsEscape("Πρόγραμμα Φυσικής Γ' Λυκείου")));
  results.forEach(function(r, idx){
    var uid = "physc-" + r.date.replace(/-/g,'') + "-" + r.period + "-" + idx + "@kathimerinotita";
    var summary = (r.type==='review' ? "Επανάληψη: " : "Φυσική: ") + r.chapter;
    var desc = r.label;
    if(r.note) desc += "\n\nΕνδεικτική δραστηριότητα: " + r.note;
    if(r.url) desc += "\n\nΥλικό επανάληψης: " + r.url;
    // Δοκιμή: εκτός από το URL στο κείμενο της περιγραφής, βάζουμε τον σύνδεσμο και στο
    // ξεχωριστό πεδίο URL: του ICS (μερικά calendar clients το εμφανίζουν ως ξεχωριστό,
    // εγγυημένα clickable κουμπί/σύνδεσμο — δεν είναι σίγουρο ότι το κάνει και η Google Calendar).
    var eventUrl = r.url || "";
    if(!eventUrl && r.note){
      var m = r.note.match(/https?:\/\/[^\s]+/);
      if(m) eventUrl = m[0];
    }
    lines.push("BEGIN:VEVENT");
    lines.push(foldLine("UID:"+uid));
    lines.push("DTSTAMP:"+now);
    lines.push("DTSTART:"+toUtcStamp(r.date, r.start));
    lines.push("DTEND:"+toUtcStamp(r.date, r.end));
    lines.push(foldLine("SUMMARY:"+icsEscape(summary)));
    lines.push(foldLine("DESCRIPTION:"+icsEscape(desc)));
    if(eventUrl) lines.push(foldLine("URL:"+eventUrl));
    lines.push("END:VEVENT");
  });
  lines.push("END:VCALENDAR");
  return lines.join("\r\n");
}

  var sched = scheduleUnits(units, weeklySlots, periodTimes, startDate, endDate, holidays);
  lastResults = sched.results;

  var lessonH = chapters.reduce(function(a,c){return a+c.hours;},0);
  var reviewH = reviewHours * chapters.length;

  var html = '<div style="background:rgba(6,214,160,0.1);border:1px solid rgba(6,214,160,0.35);color:var(--grn);border-radius:4px;padding:8px 10px;font-size:12px;font-weight:700;display:flex;align-items:center;gap:6px">✓ Το πρόγραμμα δημιουργήθηκε επιτυχώς — δες την προεπισκόπηση παρακάτω και πάτα «Λήψη αρχείου .ics»</div>' +
    '<div class="ic">' +
    '<div class="ir"><span class="k">Ώρες ύλης</span><span>'+lessonH+'</span></div>' +
    '<div class="ir"><span class="k">Ώρες επανάληψης</span><span>'+reviewH+'</span></div>' +
    '<div class="ir"><span class="k">Σύνολο ωρών</span><span>'+units.length+'</span></div>' +
    '<div class="ir"><span class="k">Προγραμματίστηκαν</span><span>'+sched.scheduled+' / '+units.length+'</span></div>' +
    '<div class="ir"><span class="k">Πρώτη ημέρα</span><span>'+(sched.results[0]?sched.results[0].date:'-')+'</span></div>' +
    '<div class="ir"><span class="k">Τελευταία ημέρα</span><span>'+(sched.results.length?sched.results[sched.results.length-1].date:'-')+'</span></div>' +
    '</div>';
  if(sched.scheduled < units.length){
    html += '<div class="warn">Δεν χωράνε όλες οι ώρες πριν την ημερομηνία λήξης (' +
      (units.length-sched.scheduled) + ' ώρες περισσεύουν). Αύξησε τις εβδομαδιαίες ώρες Φυσικής ή μετακίνησε την ημερομηνία λήξης.</div>';
  }
  info.innerHTML = html;

  var prevBody = document.getElementById('prevBody');
  prevBody.innerHTML = "";
  sched.results.forEach(function(r){
    var tr = document.createElement('tr');
    if(r.type==='review') tr.className='rev';
    var lblHtml = escHtml(r.label) + (r.note ? '<br><span style="color:var(--dim);font-size:9.5px">↳ '+linkify(r.note)+'</span>' : '');
    tr.innerHTML = '<td>'+r.date+'</td><td>'+r.dayName+'</td><td>'+r.start+'-'+r.end+'</td><td>'+lblHtml+'</td>';
    prevBody.appendChild(tr);
  });
  document.getElementById('prevWrap').style.display = "block";
});
